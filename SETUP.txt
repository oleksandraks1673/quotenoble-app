SERVER-ONLY ENVIRONMENT VARIABLES
STRIPE_SECRET_KEY: Stripe secret key for the SAME MODE as price IDs (sk_test_ for test, sk_live_ for live).
STRIPE_PRICE_MONTHLY: active recurring CAD 14.99/month price for the selected mode.
STRIPE_PRICE_YEARLY: active recurring CAD 149.99/year price for the selected mode.
SUPABASE_URL: URL of the existing Quote.Noble Supabase project.
SUPABASE_PUBLISHABLE_KEY: publishable/anon key for the existing Supabase project.
STRIPE_WEBHOOK_SECRET: signing secret for the correct webhook endpoint and Stripe mode.
QUOTENOBLE_APP_URL: origin for redirects, e.g. the actual preview URL during preview testing and https://www.quotenoble.com in production.

Never expose Stripe secret keys, webhook secrets or Supabase service role keys in browser code, screenshots, GitHub or chat.
